# 골목 잉토방 메타버스

Three.js 3D 허름한 동네 토토방 + Node.js WebSocket 멀티플레이어 시제품.

## 기능
- 닉네임 입장, 최대 동시 접속 100명 목표(서버 자원에 따른 성능 검증 필요), 위치 동기화, 채팅, 물/믹스커피 마시기.
- TV 3대에 경기표 전시, 클릭해 경기별 기대값(EV) 계산.
- 경기 소스 미설정 시 2026-11-06 사용자 제공 이미지의 샘플 목록만 표시하고 **실시간 경기로 오인되지 않도록 명시**.
- 서버 `EVENTS_FEED_URL` (허가된 JSON HTTPS 엔드포인트) 설정 시 서버 시작과 매시간 신규 경기 목록을 가져옴. 화면은 1분마다 확인. `ADMIN_TOKEN` 설정 시 `/api/admin/events`에 `Bearer` 토큰으로 경기 목록 등록 가능.
- 실제 경기 영상 스트리밍·FMKorea 공식 연동·AI 자동 예측은 아직 미구현. 데이터 제공 허가/연동 필요.

## 실행
```
npm install
npm start
```
브라우저 http://localhost:3000 접속. Render Node 웹서비스 무료 플랜에서 실행 가능하나 유휴 시 슬립 등 제한 발생 가능.

## 경기 JSON 형식
```
{"matches":[{"id":"abc123","sport":"축구","a":"홈팀","b":"원정팀","date":"11/6","time":"19:00","market":"승패","comments":10,"url":"https://www.fmkorea.com/12345"}]}
```

## 운영 주의
서버 메모리 기반 이용자 및 채팅은 재시작 시 초기화됩니다. 실제 돈이나 교환 가능한 자산을 다루는 배팅 기능은 없습니다.
